# Directions créatives ouvertes — NEDEN

Pas une charte figée : des **pistes concrètes** + libertés.

## Logo (à explorer librement)
1. **Wordmark brut** — NEDEN Satoshi Black, tracking serré, blanc sur noir
2. **D miroir** — le D central en négatif / cutout très léger (palindrome)
3. **N monogramme** — favicon : N + trait path vert→cyan 1–2px
4. **Interdit créatif** : neon, 3D chrome, trop de dégradés

Inspiration logo : Linear, Vercel, Arc — géométrie + silence

## Sections — idées de composition
- **Profil** : une phrase forte + 3 valeurs en pictos qui respirent (Strand)
- **Parcours** : cards XYZ hover glow vert (pas fond vert)
- **Skills** : chips qui bougent 1–2° max, ou grille pictos stroke
- **NEDEN produit** : mock phone ou simple pills — éviter le wall of features
- **Contact** : un seul CTA orange, zéro formulaire lourd pour OAuth homepage

## App (liberté UI)
- Navy #0B1120, indigo primary — **ne pas** coller l’orange site partout
- JARVIS : orb cyan, waveform, états idle / listen / speak
- Dense mais aéré : padding 16–20 mobile

## Motion — budget
- 1 idée forte par section max
- Transform + opacity only
- Reduced motion = static OK
