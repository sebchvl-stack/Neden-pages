# Typographie NEDEN — Site & App

## Principe

Deux familles maximum. Variable fonts. Self-host WOFF2. `font-display: swap`.

## Choix retenus

| Rôle | Police | Pourquoi |
|------|--------|---------|
| **Display / titres** | **Satoshi** (Fontshare) | Géométrique, chaleureuse, startup éditorial |
| **UI / body** | **Inter** (variable) | Lisibilité écran, neutre, standard produit |
| **Mono / data** | **JetBrains Mono** ou **Geist Mono** | Chiffres clés, code, labels techniques |

## Échelle type (site)

- Hero : Satoshi Bold, tracking -0.02em, line-height 1.05–1.15
- Section titles : Satoshi Medium/Bold
- Body : Inter Regular/Medium, line-height 1.55–1.7

## App

Inter partout. Satoshi uniquement onboarding / empty states marketing.
