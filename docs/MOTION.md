# Motion & interactions — neden.fr

Inspirations : Marketing Lab, Clearpath, Sensoria, Strand, Trova, Spector, Habitline.

## Principes

1. Une idée forte par section
2. Entrées progressives (opacity + translateY, stagger)
3. Scroll-linked path (Clearpath)
4. Hover subtil (Strand pictos)
5. Hero monumental (Marketing Lab / Sensoria)
6. Respect `prefers-reduced-motion`

## Vert en soutien

Path stroke vert-mid ou dégradé vert→cyan. Success en green-light. Jamais de fond full-green.

## Stack

Framer Motion + SVG stroke-dashoffset pour le trait.
