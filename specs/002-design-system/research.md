## Color decisions

- User preference green bottle/forest/jungle → **support only** (#1B4D3E, #2D6A4F, #52B788)
- Site energy: orange #F97316 on #050505
- App product: navy #0B1120 + indigo #6366F1 (continuity with existing PWA theme)

- Site display: Satoshi (Fontshare)
- UI body both: Inter variable
